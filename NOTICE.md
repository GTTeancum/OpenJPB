# Notice

OpenJPB is an independent reconstruction project.

This repository does not contain original game assets, original executables,
PDB files, raw Ghidra projects, or raw decompiler export directories. Users
provide their own legally owned Steam or GOG installation, and those local
inputs remain outside version control.

OpenJPB is intended to sit alongside that installation as a replacement engine
that loads user-provided retail data and creates a cleaner boundary for
preservation, debugging, and mods. It is not a substitute for owning the game.
